# Changelog

November 18, 2026

## More reliable release pages

- Release pages can recover when GitHub asks Yatko to slow down its requests.

---

October 23, 2026

## Faster download lookup

- Yatko looks up the recommended file while the release page loads.
- The download button waits for a match before naming a file.

---

October 22, 2026

## Better matches for your device

- Yatko checks the contents of supported installers and archives when it needs more than the file name to choose a download.
- Refreshing the release page returns to automatic device detection after a manual platform choice.

---

October 6, 2026

## Fixed macOS app downloads

- Yatko can recommend ZIP files that contain a macOS app bundle.

---

September 2, 2026

## Embed a download button

- Open Share on a release page to copy a “Get it on Yatko” button for your README.

---

August 29, 2026

## Source downloads and checksum verification

- Use Download source code to get a ZIP archive for the selected release.
- Verify a downloaded file when the project publishes a SHA-256 checksum.

---

July 23, 2026

## Mobile downloads and repository search

- Yatko can find APK files for Android and IPA files for iOS.
- The homepage suggests GitHub repositories as you type.

---

July 16, 2026

## Swap the domain

- Replace github.com with yatko.app in a repository URL to open its download page.
